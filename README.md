# DNSFrenzy

Fastest DNS auto-switcher for Windows.

Pings a list of DNS servers, applies the fastest one.

## Use

1. Extract DNSFrenzy-Portable.zip from Releases
2. Right-click DNSFrenzy.exe -> Run as administrator
3. Run test -> Apply fastest

## Edit servers

Open config/servers.txt. One server per line:

    Name | Primary | Secondary

Lines starting with # are ignored.
